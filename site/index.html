L'agent, enfin visible

Vous voyez ce qu'il fait,
au moment où il le fait.

Chaque événement de votre agent devient un geste. Ework ne fait pas semblant : il suit les outils que l'agent utilise, ses réponses et ses questions.

  1. 01

    Vous lui parlez

    Un clic sur Ework : sa bulle s'ouvre au-dessus de lui. Vous écrivez, il écoute. Ou bien un raccourci, d'où que vous soyez.

  2. 02

    Il réfléchit

    L'agent prépare sa réponse sur son serveur. Ework le montre, sans terminal ni journal à lire.

  3. 03

    Il cherche, il lit, il range

    Une recherche sur le web, un fichier à lire, un dossier à ranger : chaque outil a son geste.

  4. 04

    Il vous demande votre accord

    Avant d'envoyer un e-mail ou de lancer une commande, l'agent demande. Vous approuvez ou refusez d'un clic, même quand Ework est caché.

  5. 05

    C'est fait

    La réponse s'écrit dans la bulle, le compteur avance, et Ework fête ça. Sobrement.

pièce par pièce.

Couleur, yeux, bouche, couvre-chef, lunettes, col. Certaines pièces se gagnent avec le temps. Essayez ici, c'est le même Ework que dans l'application.

Il vit avec vous

Un café le matin, une sieste le soir.

Il suit l'heure de votre journée, réagit à une copie, à la musique, à un fichier qu'on lui tend. Et dès qu'une application passe en plein écran, il se fait oublier.

Pour les développeurs

Branché sur l'API Hermes,
rien de plus.

Ework parle le langage standard de Hermes : les missions (runs), leur flux d'événements, les accords, les sessions, les tâches planifiées. Votre agent sait le relier lui-même.

Votre agent active son serveur d'API, puis répond par une seule ligne. Collez-la dans Ework : la clé va directement dans le trousseau du système.

# ~/.hermes/.env de votre agent
API_SERVER_ENABLED=true
API_SERVER_KEY=••••••••••••

# la ligne à coller dans Ework
ework://connect?url=https://agent.exemple.fr&key=••••

Un script de votre agent prévient Ework quand il le décide. Ework écoute sur votre ordinateur, protégé par un jeton créé par lui, et ne fait qu'afficher : il n'exécute jamais rien de ce qu'il reçoit.

curl -X POST http://100.64.0.12:47800/notice \
  -H "Authorization: Bearer $EWORK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"Sauvegarde","text":"Terminée en 42 s","level":"info"}'
