# Sécurité

Vous pensez avoir trouvé une faille de sécurité dans Ework (mise à jour, stockage de la clé, connexion à l'agent…) ?

**N'ouvrez pas de ticket public.** Utilisez le bouton « Report a vulnerability » de l'onglet [Security](../../security/advisories/new) de ce dépôt : le signalement reste privé.

Seule la dernière version publiée est suivie. Les installeurs officiels ne sont publiés que dans les [versions de ce dépôt](../../releases), compilés par GitHub Actions et accompagnés de leurs empreintes SHA-256.
